# Mouvements (motion capture)

Extraits de la base **CMU Graphics Lab Motion Capture Database**
(http://mocap.cs.cmu.edu), version BVH de Bruce Hahne (cgspeed).
Données fournies gratuitement pour tout usage ; le laboratoire demande de
citer : « The data used in this project was obtained from mocap.cs.cmu.edu.
The database was created with funding from NSF EIA-0196217. »

Clips utilisés : 86_15 (assis), 79_72 (pleurs), 22_03 (visage dans les mains),
22_21, 19_10 (dispute), 19_08 (explication), 40_10 (attente debout),
17_01 (marche). Convertis en rotations relatives à la pose en T.
